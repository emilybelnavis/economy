# Economy branding

**Economy** · **Banking. Cash. Commerce.**

The primary mark is a stepped gold coin with a block-built capital E. The banner pairs it with cream pixel-inspired lettering on deep forest green. Keep the identity distinct from the fictional bank and card-network brands inside the mod.

## Colour and typography

| Colour | Reference | Role |
| --- | --- | --- |
| Gold | `#F4BE35` | Coin and accents. |
| Forest | `#122D26` | Banner background. |
| Cream | `#FFF0C8` | Wordmark and supporting text. |

These are reference colours for companion layouts; generated artwork contains shading. Use squared, pixel-inspired display lettering for the wordmark and ordinary readable type for documentation. The banner lettering is baked into the artwork; no external font is bundled.

Keep the icon's transparent margin, proportions, rim and E intact. Use the icon alone at small sizes and the full banner where its tagline remains readable. Avoid stretching, recolouring or adding effects. The mod listing uses nearest-neighbour sampling to retain hard edges.

## Provenance

Created for Economy with the built-in imagegen tool; no third-party artwork or font files were supplied. The banner uses the generated icon as its identity reference.
