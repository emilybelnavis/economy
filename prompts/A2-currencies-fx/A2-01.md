# A2-01 — Currency registry and monetary types

Approved. Implement only after A1 acceptance and review of the [shared contract](CONTRACT.md).
Owner: A2 currency domain. Deliver an immutable server registry and shared
money, price and formatting contracts. No persistence, network writes or scheduling.

the last pre-reset revision, b993a39^. The last column is the exact historical

Currencies and scales are fixed. Format in the player locale and include the
code wherever context does not identify the currency. Formatting does not
change stored amounts. Proposed: checked signed 64-bit minor units, exact
fractional prices represented separately, and en-CA locale fallback.
Reject unknown codes, mixed-currency arithmetic and overflow. Callers own
sign rules. A3 owns account-specific caps.

Gate: verify every fixture, both scales, localized formatting and code
disambiguation, signed boundaries and rejection cases. Hand off to A2-02
and A3/A4. Exclude conversions, balance rules and physical denominations.
