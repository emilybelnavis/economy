# A2-03-01 — Daily FX scheduling and configuration

Approved. Prerequisites: verified A2-02 and [shared contract](CONTRACT.md).
Owner: A2 FX publication. Deliver the opening publication contract and a
versioned A1 clock registration. Use a trusted selection fixture until A2-05.
At opening divide each historical CAD fixture rate by the selected reference's
fixture rate. Publish the reference at exactly 1. Rates are reference units per
one major unit. Publish each complete set at 12 decimal places, half-even.

Starting the next UTC midnight, process each due day in order. For each
floating currency start with the previous published rate, add the configured
pull times the gap to the effective baseline, add the draw times that
baseline, then apply the configured band and publication precision. Defaults
are ±0.30% uniform daily variation, 10% pull, and ±5% bounds. Sustained trend
is zero in this release. CAD floats when another currency is the reference.

Authorized admins can edit baselines, variation, pull and bounds effective
the next UTC midnight. Carry yesterday's rate forward under the new policy,
including immediate new bounds. Resolve policies by scheduled day, retaining
effective versions and published history. Proposed: enter baselines in the
permanent reference units, use the last durably saved edit for a given
midnight, and validate positive representable bands within 10^-12 through
1,000,000. Define allowed configuration ranges and reject invalid policies
before publication. Clamp within the representable 12-place band so rounding
preserves it.

Proposed draw contract: derive a currency-specific digest from the A1
deterministic update seed, canonical currency code and a versioned domain
separator. Map with rejection sampling to a uniform integer across the
configured inclusive ppm range (default −3000 through +3000). Pin byte
encoding, rejection counter and golden vectors before implementation.

Store immutable versioned publication facts and a bounded lookup index in the
same world database. Persist rate day, reference, all rates, update identity
and effective policy identity. Journal publication, index effects and clock
completion atomically. Keep historical decoders and rebuild derived views
from recorded outcomes. Reject duplicate or partial day publication and
resolve uncertain commits through A1. No live rate feeds, player chooser,
quotes or trades.

Gate: verify trusted fixture opening, reference rebasing including DKK/JPY,
next-midnight activation, baseline carry-forward, repeatable draws, settings
validation, no preselection backlog, and rollback without partial publication.
Hand off committed state and failure reasons to A2-03-02.
