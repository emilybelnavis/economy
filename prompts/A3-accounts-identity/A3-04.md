# A3-04 — Funds vocabulary and account queries

Execution draft. Requires explicit invocation and the [shared execution contract](CONTRACT.md).

## Prerequisites

Verified A3-03 and A2 monetary types.

## Deliverable

Define versioned per-currency views in checked minor units. Available, reserved and restricted funds are disjoint; A4 owns ledger calculations, claims and any signed system exceptions. Return ledger unavailable until A4 provides the projection. Authorize each stable-ID lookup and bounded cursor page in a consistent read snapshot. Expose audited cross-party inspection through A3-01 server-operator authority.

## Acceptance gate

Verify absence and unauthorized discovery are indistinguishable to ordinary callers, operator inspection is audited, malformed cursors and oversized pages are rejected, and paging remains bounded across lifecycle changes. Use fixtures to verify category arithmetic and overflow handling. Record verification and the next-package handoff.

## Exclusions

Postings, holds implementation, operator mutations and public packet or UI wiring.
