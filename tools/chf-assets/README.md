# Original CHF cash artwork

The editable source is `generate.py`. Run `python3 tools/chf-assets/generate.py`
from the repository to regenerate the thirteen CHF item textures and models.
It uses only the Python standard library and writes only `chf_*.png` / matching
item models. Generated images are deterministic 64×64 RGBA pixel artwork with
transparent backgrounds, matching the existing cash icon canvas.

The six notes use independently authored Alpine silhouettes, snowy ridges,
stepped river bands, geometric windows, denomination edge indexes and distinct
palettes. Seven coins use different diameters and bronze, silver, brass, blue
silver, gold and bimetal-inspired pixel palettes. Every face includes CHF and
its value using an original hand-authored 3×5 bitmap alphabet.

No official Swiss note, coin, bank logo, portrait, font file or photograph was
sampled or traced. No external image or font dependency is used. The original
118 cash textures/models and eight card textures/models are untouched.
Financial identity and value remain server catalog data, never artwork.

provided under **CC0-1.0** (SPDX identifier). This provenance statement applies
only to the files authored here, not to existing project assets.
